# Naveen Kumar — Personal Portfolio

A responsive, professional portfolio website built with plain HTML, CSS and JavaScript. It is ready for GitHub Pages.

## Publish on GitHub Pages
1. Create a new GitHub repository, e.g. `naveen-kumar-portfolio`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide your public website URL.

The content is based on the uploaded Naveen Kumar resume.
